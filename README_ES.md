# ProFair Observability

**ProFair Observability** es un marco computacional abierto y reproducible
para medir cómo las ferias profesionales hacen observables los mercados de
forma selectiva mediante organizaciones y relaciones
persona–organización–feria.

La salida principal es un **perfil multidimensional**, no un índice único. El
índice compuesto está desactivado por defecto y solo debe utilizarse cuando
existan benchmarks explícitos, ponderaciones justificadas y evidencia
suficiente de validación.

## Dimensiones

- presencia demográfica;
- inclusión organizacional;
- representación en liderazgo;
- similitud de distribuciones funcionales;
- representación espacial ponderada por superficie;
- similitud de distribuciones geográficas.

## Protección de datos

El repositorio público nunca debe contener datos administrativos reales,
nombres, correos, teléfonos, direcciones, claves restringidas de enlace ni
perfiles profesionales identificables.
